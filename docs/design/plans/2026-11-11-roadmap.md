# Public roadmap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `roadmap/roadmap.md`, a hand-edited roadmap that an agent reads as specs, published as a visual page on GitHub Pages that rebuilds on every merge.

**Architecture:** One zero-dependency Node tool, `tools/roadmap.js`, parses the file (`check`, run on every PR) and renders a static page from the template in `roadmap/site/` (`build`, run by a new Pages workflow). `npm run version:bump` stamps the release onto shipped items.

**Tech Stack:** Node ≥ 20 CommonJS, `node:test`, plain HTML/CSS/JS, GitHub Actions (`actions/upload-pages-artifact`, `actions/deploy-pages`).

**Spec:** `docs/design/specs/2026-11-11-roadmap-design.md` (D1–D13 below refer to it).

## Global Constraints

- Zero new dependencies, runtime or dev. CommonJS, `'use strict'`, `node:test` + `node:assert/strict`, macOS and Linux.
- Run tests with `npm test` or `node --require ./tools/test-env.js --test <file>`, never a bare `node --test`.
- No absolute home path, real name or email address in any file, commit or PR; `npm run gate -- --require-private` stays clean. Public files call the build agent "an agent".
- Statuses, exactly: `idea`, `planned`, `approved`, `building`, `shipped`. Types: `feature`, `function`, `improvement`. ID: `UDX-` + at least 3 digits. Release: `v` + semver (`/^v\d+\.\d+\.\d+(-[0-9A-Za-z.-]+)?$/`). Area: `/^[a-z][a-z0-9-]*$/`.
- Separators in the heading and the metadata line: `·`, `-`, `–`, `—`, `|`. Metadata keys and the status and type values are case-insensitive and stored lowercase.
- The page loads nothing from outside its own folder. Address: `https://zzoretich.github.io/UniDeX-Agent-Harness/`.
- British spelling ("colour"), as the rest of the repo.
- Commits: conventional prefix, ≤ 72 chars, author `zzoretich` with the noreply email, message ends with only `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never `--no-verify`.
- Actions pinned to full commit SHAs with the version in a comment.

## Review Focus

1. Edits from GitHub's web editor or another OS: CRLF line endings, trailing spaces, `Idea` capitalised. They must parse exactly like the clean form. Test: Task 1 `tolerant input`.
2. A plan section containing a fenced code block with `###` or `####` lines inside. Those lines stay prose and render as a code block. Tests: Task 1 `fences`, Task 2 `renderMarkdown`.
3. `<`, `"` or `&` in a title, prose with `<script>`, or a `javascript:` link. All of it must be escaped in cards, panels and attributes. Test: Task 2 `escaping`.
4. Empty lanes, only shipped items, zero items. The page still builds, and each empty lane says "Nothing here yet". Test: Task 2 `empty`.
5. A pre-release bump (`2.7.0-rc.1`). It stamps nothing, so shipped items stay under "Next release". Test: Task 3.

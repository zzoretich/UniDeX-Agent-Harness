# UniDeX 2.0: build plan

Specs: `docs/design/specs/2026-10-14-local-first-design.md` (A1–A18), `2026-10-14-install-and-import-design.md` (B1–B15), `2026-10-14-guided-tour-design.md` (C1–C13). Ten PRs in three tracks merge to `main` as each is ready; **one release, 2.0.0, ships them together** (owner's decision), so existing users get the Go-local card, the import and the tour in one update. Each PR runs the new-feature skill's verify and publish check before it opens. Code comments cite `local-first A<n>`, `install-import B<n>`, `tour C<n>`.

**`main` between PRs.** Every PR leaves `main` green and coherent, but `main` is not released until 2.0.0. A fix for 1.9 users in the meantime ships from a `release/1.9` branch cut at `v1.9.0`.

## Order

```
wave 1 (parallel)   PR 1  A  local engine          PR 5  B  toolchain, host optional     PR 8  C  tour engine + chapters
wave 2              PR 2  A  background goes local PR 3  A  CoS models + tick triage      PR 6  B  importer (runtime)
wave 3              PR 4  A  routine engines + local runner                              PR 7  B  import in the app (wizard, Sessions, MCP)
wave 4              PR 9  launch sequence: migrations, Go-local card, Import sheet, What's new 2.0   (needs 2, 3, 4, 7, 8)
wave 5              PR 10 the tour CI rule, docs rewrite, 2.0 content audit                         (needs 9)
release             2.0.0 → release:app → §8 on an existing install → §0–§7 in a fresh macOS account
```

## Risks

| Risk | Mitigation |
|---|---|
| A 4B or 9B model writes poorer summaries, extractions and triage than Haiku | JSON-schema `format`; fixture tests; heuristics behind every call; Review keeps a human on memories |
| Tool calling on small local models is unreliable | the runner caps turns, validates tool arguments, journals failures; the editor warns; hosted engines stay one click away |
| Memory pressure on 8 and 16 GB Macs | RAM tiers; `keepAlive 5m` below 24 GB; heavy jobs defer on battery |
| Third-party downloads (Node, uv, Ollama, CLIs) | pinned checksums and codesign checks; failures delete the download; a security review on the other provider |
| Opus 5.5 / gpt-6-sol duties cost more per run | the tick no longer calls the CoS on quiet hours; duty caps unchanged; the Go-local card shows last week's spend |
| A migration overwrites a choice | ask once; backup; Undo; user routines never touched |
| A long gap before 2.0 ships | `release/1.9` for fixes; waves 1–3 parallel in separate worktrees |
